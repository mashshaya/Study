# ML In Economics Project

Проект по машинному обучению в экономике о зависимости месячных трат клиента от наличия премиум-подписки на сервис доставки.

## Содержимое

- `Отчет_по_проекту.pdf` — итоговый отчет.
- `calculations.ipynb` — чистовой ноутбук с генерацией данных, классификацией, регрессией и оценкой эффектов воздействия.
- `data/` — сгенерированные датасеты, которые используются в разных блоках ноутбука.

## Как воспроизвести расчеты

Открой `calculations.ipynb` из папки `project` и запусти ячейки сверху вниз. Ноутбук сам генерирует датасеты и сохраняет их в `data/`.
