# Краткое саммари ноутбука `project_analysis.ipynb`

**Тема:** Влияние загрязнения воздуха на ожидаемую продолжительность жизни в регионах РФ (2015).
**Данные:** `validated_dataset_extended.csv`, кросс-секция, N = 85 регионов.

## Переменные модели

- **Y (DV):** `life_expectancy` — ожидаемая продолжительность жизни при рождении.
- **Эндогенный регрессор:** `ln_emissions_h1_pc` — log выбросов на душу (I пол. 2015).
- **Инструмент (IV):** `ln_emp_mining_pc` — log доли занятых в добыче полезных ископаемых.
- **Контроли:** `ln_grp_pc`, `urban_share`, `age_struct_share`, `ln_population_avg`.

## Построенные модели

1. **First-stage OLS** — релевантность инструмента:
   `ln_emissions_h1_pc ~ ln_emp_mining_pc + controls` (HC1 robust SE).
2. **Сравнительные first-stage регрессии** для альтернативных IV:
   `ln_emp_energy_pc`, `ln_emissions_fuel_pc`.
3. **Базовый OLS:** `life_expectancy ~ ln_emissions_h1_pc + controls` (HC1).
4. **2SLS (IV2SLS):** та же спецификация, эмиссии инструментируются `ln_emp_mining_pc`.

## Проведённые тесты и проверки

- Проверка качества выборки: дубли, пропуски, не-конечные значения в логах → чисто (N = 85, 0 пропусков в основных переменных).
- Дескриптивная статистика и гистограммы по DV / `ln_emissions_h1_pc` / `ln_grp_pc`.
- Корреляционная матрица 7 основных переменных.
- Анализ выбросов (НАО, ЯНАО, ХМАО, Севастополь, Чукотка) — без удаления.
- **F-test на исключённый инструмент** (правило F ≥ 10; Stock-Yogo crit. 16.38 на 10%).
- **Сравнение OLS vs 2SLS** по коэффициенту при эндогенной переменной (намёк на Хаусман).

## Ключевые результаты

| Связь / модель | Оценка |
|---|---|
| corr(`life_exp`, `ln_emissions_h1_pc`) | **−0.52** (знак гипотезы подтверждается) |
| corr(`ln_emissions_h1_pc`, `ln_emp_mining_pc`) | **+0.65** (IV relevance) |
| First-stage: коэф. на IV | **+0.384**, p < 0.001, **F = 13.5** |
| OLS β при `ln_emissions_h1_pc` | **−1.17** (t = −5.82, p < 0.001) |
| 2SLS β при `ln_emissions_h1_pc` | **−1.60** (t = −3.79, p < 0.001) |
| R² OLS / 2SLS | 0.53 / 0.50 |

Альтернативные IV (`ln_emp_energy_pc` F=23, `ln_emissions_fuel_pc` F=61) имеют более высокую релевантность, но **нарушают exclusion** (прямая связь с DV / механическое вложение в эндогенный регрессор), поэтому отклоняются.

## Выводы

1. **Гипотеза подтверждается:** рост атмосферных выбросов на душу значимо снижает ожидаемую продолжительность жизни.
2. **OLS смещён к нулю** (attenuation): 2SLS даёт более сильный отрицательный эффект (−1.60 vs −1.17), что согласуется с эндогенностью эмиссий.
3. **Инструмент `ln_emp_mining_pc` приемлем:** F = 13.5 > 10 (правило большого пальца), но между Stock-Yogo crit. 15% (8.96) и 10% (16.38) — *moderately strong*. Выбор оправдан содержательно: добыча локализована геологически, влияет на здоровье именно через канал загрязнения воздуха.
4. **Контроли ведут себя ожидаемо:** после контроля выбросов `ln_grp_pc` становится положительным (+1.6…+2.3) — парадокс «нефтегазовых регионов» снимается; `ln_population_avg` (+1.0) — эффект мегаполисов.
5. **Ограничения:** кросс-секция 2015 (нет within-вариации), занятость на 2017 (proxy), полугодовые эмиссии, N = 85 ограничивает мощность over-id тестов.

**Финальная спецификация для proposal:** 2SLS с HC1, IV — `ln_emp_mining_pc`, ожидаемый $\hat{\beta}_1 \approx -1.6$, значим на 1%.
