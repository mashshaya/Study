# METRICS-2

Проект по эконометрике о влиянии загрязнения воздуха на ожидаемую продолжительность жизни в регионах России.

## Содержимое

- `Отчет_по_проекту.pdf` — итоговый отчет с нейтральным названием файла.
- `calculations.ipynb` — чистовой ноутбук с расчетами, EDA, OLS/IV-моделями и диагностическими тестами.
- `validated_dataset_extended.csv` — подготовленный датасет для запуска ноутбука.

## Как воспроизвести расчеты

Открой `calculations.ipynb` из папки `METRICS-2` и запусти ячейки сверху вниз.
