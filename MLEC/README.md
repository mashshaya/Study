# MLEC

Материалы по курсу машинного обучения.

## Структура

- `Homeworks/` — домашние работы.
- `Project/` — основной проект с расчетами.
- `data/` — общие датасеты для домашних и проекта.
- `archive/alternative_notebooks/` — отличающиеся версии ноутбуков, сохраненные на всякий случай.
- `lectures/` и `seminars/` — учебные материалы курса.

Дубликаты данных и zip-архивы удалены: один и тот же датасет Booking.com хранится только как `data/booking_reviews.csv`.
