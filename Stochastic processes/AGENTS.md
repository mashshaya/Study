# AGENTS.md

## Цель проекта

Проект нужен для практического изучения случайных процессов в Python.

Главная задача каждого ноутбука — не просто реализовать модель, а наглядно показать:

* как выглядит процесс;
* как меняются его траектории;
* как параметры влияют на поведение;
* как теоретические свойства проявляются в симуляциях;
* что видно на графиках и в численных результатах.

Делай больше содержательных визуализаций, сравнений параметров и вычислительных экспериментов.

## Структура проекта

```text
AGENTS.md
STUDY_PLAN.md
Practice/
Scripts/
Literature/
```

* `Practice/` — учебные Jupyter-ноутбуки.
* `Scripts/` — Python-функции для симуляций, вычислений и визуализаций.
* `Literature/` — лекции и дополнительная литература.
* `STUDY_PLAN.md` — план тем и содержание ноутбуков.

## Функциональный подход

Максимально используй функциональный подход.

Основную логику пиши в Python-файлах внутри папки `Scripts/`:

* симуляцию процессов;
* вычисление статистик;
* сравнение теории с симуляциями;
* построение графиков;
* повторяющиеся вычисления.

В ноутбуках оставляй преимущественно:

* теорию и объяснения;
* импорт функций из `Scripts/`;
* задание параметров;
* вызов функций;
* отображение результатов;
* интерпретацию графиков и чисел.

В ноутбуках не должно быть больших блоков реализации.

Предпочтительный стиль:

```python
from Scripts.brownian_motion import (
    simulate_multiple_brownian_motion_paths,
    plot_brownian_motion_paths,
)
```

```python
time_grid, simulated_paths = simulate_multiple_brownian_motion_paths(
    number_of_paths=1000,
    number_of_time_steps=500,
    final_time=1.0,
    random_seed=42,
)

plot_brownian_motion_paths(
    time_grid=time_grid,
    simulated_paths=simulated_paths,
)
```

## Требования к функциям

Функции должны:

* выполнять одну понятную задачу;
* принимать параметры явно;
* возвращать результат;
* не зависеть от скрытых глобальных переменных;
* использовать понятные имена;
* иметь type hints и короткие docstrings;
* использовать воспроизводимый генератор случайных чисел.

Названия функций должны быть длинными и исчерпывающими.

Хорошо:

```python
simulate_multiple_brownian_motion_paths
calculate_empirical_mean_and_variance_across_paths
plot_theoretical_and_empirical_terminal_distributions
estimate_first_passage_time_distribution
```

Плохо:

```python
simulate
run
calc
process
plot_data
helper
```

По названию функции должно быть понятно, что она делает и какой объект обрабатывает.

## Требования к ноутбукам

Для каждой темы:

1. Кратко объясни теорию и смысл модели.
2. Опиши параметры процесса.
3. Импортируй функции из `Scripts/`.
4. Построй одну и несколько траекторий.
5. Покажи влияние ключевых параметров.
6. Сравни теоретические и эмпирические характеристики.
7. Добавь графики и численные результаты.
8. После каждого эксперимента объясни, что именно видно.
9. В конце сформулируй основные выводы.

Каждый график должен иметь:

* понятный заголовок;
* подписи осей;
* легенду при необходимости;
* краткую интерпретацию.

## Работа с литературой

При необходимости используй материалы из папки `Literature/`.

Не копируй большие фрагменты. Пересказывай теорию своими словами и связывай её с кодом, симуляциями и визуализациями.

## Ограничения

* Работай только над указанной темой.
* Не переходи к другим ноутбукам без запроса.
* Не создавай сложную архитектуру.
* Не создавай классы, если задачу можно решить функциями.
* Не дублируй существующие функции.
* Не помещай большие реализации непосредственно в ноутбук.
* Не выполняй чрезмерно тяжёлые симуляции.
