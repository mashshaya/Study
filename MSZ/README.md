# MSZ

Материалы по курсу МСЗ, разложенные по домашним работам и контрольным проектам.

## Структура

- `Homeworks/` — домашние и семинарские работы в формате `HW##_topic`.
- `Projects/` — midterm-проекты.

В каждой папке основной ноутбук называется `calculations.ipynb`, а входные данные лежат в `data/`.
