# METRICS-1

Проект по эконометрике о факторах, определяющих цены бриллиантов.

## Содержимое

- `Отчет_по_проекту.pdf` — итоговый отчет без фамилий в названии файла.
- `calculations.ipynb` — чистовой ноутбук с расчетами и эконометрическим анализом.
- `diamonds.csv` — входные данные для запуска ноутбука.

## Как воспроизвести расчеты

Открой `calculations.ipynb` из папки `METRICS-1` и запусти ячейки сверху вниз.
