# MACRO

Домашняя работа по макроэкономике о бюджетном правиле в Республике Казахстан.

## Содержимое

- `Ковалёва_Серова_Белоконова.docx` — чистовой текст работы.
- `calculations.ipynb` — чистовой ноутбук с расчётами.
- `macro_data.csv` — входные данные, необходимые для запуска ноутбука.

## Как воспроизвести расчёты

Открой `calculations.ipynb` из папки `MACRO` и запусти ячейки сверху вниз.
