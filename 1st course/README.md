# 1st course

Материалы первого курса разложены по предметам и типам занятий.

```text
1st course/
├── Calculus/
│   ├── Lectures/
│   └── Seminars/
└── Linear Algebra/
    └── Lectures/
```

## Соглашение

- `Lectures/` — конспекты и слайды лекций.
- `Seminars/` — материалы семинаров и практических занятий.
- Новые материалы лучше добавлять сначала в папку предмета, затем в папку типа занятия.
