# TS

Материалы по курсу временных рядов.

## Структура

- `Homeworks/` — домашние работы в едином формате `HW##_topic`.
- `Projects/` — крупные контрольные/проектные работы.
- `Theory/` — теоретические конспекты, лекционные материалы и небольшие учебные датасеты.

## Формат работ

В каждой работе по возможности используется одинаковая структура:

- `calculations.ipynb` — основной ноутбук с расчетами.
- `report.pdf` — итоговый отчет, если он есть.
- `data/` — входные и подготовленные данные.
- `figures/` — графики.
- `results/` — таблицы и другие выходные файлы.
- `scripts/` — вспомогательный код.
