# Project 02: Control Work

Вторая контрольная работа по временным рядам: подготовка месячного датасета, диагностика рядов, VAR-анализ и интерпретация результатов.

## Содержимое

- `calculations.ipynb` — чистовой ноутбук с основными расчетами.
- `report.pdf` — итоговый отчет.
- `report.tex` — исходный LaTeX отчета.
- `original_assignment.pdf` — исходный файл задания.
- `data/processed/` — итоговый датасет и отчет о сборке.
- `data/raw/` — raw-файлы, использованные в чистовой версии.
- `data/source_archive/` — полный архив исходных выгрузок, сохранен на всякий случай.
- `figures/` — графики отчета.
- `scripts/` — код чтения и сборки данных.
- `checks/` — проверочные и черновые ноутбуки, сохраненные отдельно от чистовой версии.
- `results/legacy_outputs/` — старые выходные файлы, оставлены как архив.
