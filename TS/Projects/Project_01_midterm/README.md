# Project 01: Midterm

Промежуточный проект по анализу временных рядов на данных World Bank.

## Содержимое

- `calculations.ipynb` — основной ноутбук с расчетами.
- `report.pdf` — итоговый отчет.
- `report.tex` — исходный LaTeX отчета.
- `data/` — входные CSV-данные и metadata.
- `figures/` — графики из анализа.
