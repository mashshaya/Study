# Theory

Учебные конспекты и практические ноутбуки по теории временных рядов.

## Содержимое

- `01_intro_trend_smoothing.ipynb` — введение, тренд и сглаживание.
- `02_stationarity_autocorrelation.ipynb` — стационарность и автокорреляция.
- `03_stationary_models.ipynb` — стационарные модели временных рядов.
- `data/` — небольшие датасеты для теоретических ноутбуков.
- `lecture_notes/` — дополнительные материалы лекций.
