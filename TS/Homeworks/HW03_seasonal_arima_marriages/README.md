# HW03: Seasonal ARIMA For Marriages

Домашняя работа по анализу сезонного временного ряда браков и краткосрочному прогнозированию.

## Содержимое

- `calculations.ipynb` — основной ноутбук с расчетами.
- `report.pdf` — итоговый отчет.
- `report.tex` — исходный LaTeX отчета.
- `data/` — исходные и очищенные данные.
- `results/` — прогнозные таблицы.
- `figures/` — графики диагностики и прогнозов.
