# HW04: VAR Unemployment

Домашняя работа по VAR-анализу региональных рядов безработицы.

## Содержимое

- `calculations.ipynb` — основной ноутбук с подготовкой данных, оцениванием VAR и диагностикой.
- `report.pdf` — итоговый отчет.
- `report.tex` — исходный LaTeX отчета.
- `data/` — исходные и очищенные данные.
- `figures/` — графики анализа.
- `results/tables/` — таблицы с результатами моделей и тестов.
- `scripts/` — вспомогательные скрипты сборки.
