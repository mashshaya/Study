# COURSEBOOK

Курсовой проект по моделям оценки опционов и сравнению качества моделей на данных MOEX.

## Содержимое

- `Курсовая_Ковалёва.pdf` — итоговый текст курсовой работы.
- `final/calculations.ipynb` — основной ноутбук с расчётами, таблицами и графиками.
- `final/options_utils.py` — вспомогательные функции для ценообразования опционов, расчёта метрик и статистических тестов.
- `final/mm_options_with_mxi_underlying_2024_2026.parquet` — подготовленный датасет, необходимый для запуска расчётов.

## Как запустить расчёты

Открой `final/calculations.ipynb` и запусти ячейки сверху вниз из папки `final`.
Ноутбук создаст промежуточные таблицы и графики в `final/results_models/`.
